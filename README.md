# SAE S1.04: Report website

A static, multi-page website (HTML/CSS) presenting the report for the first-year university project **SAE S1.04**, part of the BUT Informatique at Université Paris Cité (2024).

> Group 105: Lukas Lieu, **Titouan Le Neun**, Tarik Mohamed, Maxence Amalfi.

## Pages
- `Accueil.html`: home page and navigation
- `Introduction.html`
- `mission_1.html`, `mission_2.html`, `mission_3.html`: one page per project mission
- `Conclusion.html`

## Tech
HTML5, CSS3 (`style.css`). No framework, no build step.

## View it
Download or clone the repo and open `Accueil.html` in a browser.
